# Pentagon flange pairs — every stock size

A matched gear-side and cap-side centering ring for **each original Kraken size from 45 through 95 mm**, in 1 mm steps. These extend the design of the [55.5 mm pair](../README.md); they are new generated sizes, not claims of physical fit on 51 different spools.

Choose the nominal size from the spool's measured centre hole. Each pair uses that size's original humebeam holder bore and snap geometry; these interfaces are not scaled with the outside diameter. The five outer corners are intended to grip cardboard. The interference is not qualified for rigid plastic hubs.

![Actual 45, 55.5 and 95 mm ring pairs at the same scale](images/family.png)

## Shared dimensions

| Parameter | Value |
|---|---:|
| Round support radius | Nominal hole radius − 0.10 mm |
| Five corner radius | Nominal hole radius + 0.70 mm |
| Corner phase | First corner at +Y; 72° spacing |
| Lead-in | Last 2.0 mm, reducing corner radius by 1.9 mm |
| Gear-side flange | 1.5 mm thick; 10.25 mm radial reach beyond nominal hole |
| Gear flange outside diameter | Nominal hole diameter + 20.5 mm |
| Cap-side lip | Original 0.4 mm source lip |
| Insertion length | Retained from the corresponding source ring |

As with the existing 55.5 mm pair, the thicker gear-side flange shifts the spool seating face by 1.1 mm while preserving insertion length. It does not imply that the bearing-located gear moves away from the body wall.

STEP files are gzip-compressed: decompress `.step.gz` before importing into CAD. They are faceted solids with 0.00001 mm numerical topology cleanup, not smooth native CAD or increased mesh resolution.

## Checks and reproduction

[Geometry validation](VALIDATION.json) covers all 102 parts: a single valid mesh, source-interface preservation, the thicker flange's source bore section, nominal height, Z0 placement, and STL/3MF export comparisons. [STEP read-back checks](STEP-CHECKS.json) cover the faceted solid exports and disclose numerical cleanup. Neither report certifies physical shrinkage, snap force, cardboard damage or installed spool clearance.

The smallest sizes need a smaller retained-core envelope so the old outer wall does not obstruct the new lead-in. That envelope is derived from the lead-in radius and remains outside the original holder-interface surfaces. The source-interface comparisons still apply.

Rebuild with the [repository dependencies](../../requirements.txt), from the repository root:

```sh
python rings/source/generate_family.py --output pentagon-build
python rings/export_step.py pentagon-step-build --input pentagon-build/models --gzip --workers 2
```

The first command rebuilds every stock size. For a subset, add `--sizes 45 55 95`. Both commands require new output directories. The generators use simple repeated circle/pentagon extrusions and a tapered lead; source meshes preserve the supplied snap and bore surfaces. See [source provenance](../source/README.md).
