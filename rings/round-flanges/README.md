# Earlier round gear-side flanges

These are the existing round centering-ring revisions, copied unchanged. They retain the stock round outer profile and replace its 0.4 mm lip with a 1.5 mm gear-side flange reaching **20 mm radially beyond the hole**. This is a wider flange than the later [pentagon family](../stock-sizes/README.md), which uses a 10.25 mm reach.

These files contain the **gear-side ring only**. Pair with the corresponding original humebeam cap-side ring. Choose by measured spool hole. The family has not been physically fit-tested across every size.

STL coordinates retain the original source placement: centre the part and move its flat flange underside onto the bed in your slicer. The model files do not contain print settings.

## Reproduction

[Validation](VALIDATION.json) checks all 51 meshes and byte-identical regeneration. From the repository root, using its CAD dependencies:

```sh
python rings/source/round_flange.py rings/source/reference round-flange-build
```

Use a new output directory. The script remaps the original lip and raises the insertion section by 1.1 mm; it does not scale the holder bore radially. Original meshes are attributed in the [source notes](../source/README.md). The changed flange does not by itself prove increased gear-to-body clearance.
